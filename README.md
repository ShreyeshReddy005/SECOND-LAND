## The Problem
Prime land in Hyderabad's IT Corridors (Madhapur, Gachibowli) is virtually exhausted. Developers must build vertically using **Transferable Development Rights (TDR)**. But modeling the financial feasibility of buying air rights is currently done in opaque, disjointed Excel spreadsheets that strip away geographic reality. 

**Raw government TDR data is messy, unstructured, and impossible to map.**

## The Solution: SECOND LAND
SECOND LAND is an institutional-grade proptech dashboard that transforms unstructured government data into a live spatial underwriting engine. 

We threw away the spreadsheets and built a **System 1 AI ETL Pipeline** that reads, structures, and financially underwrites government records deterministically. 

### 🧠 TypeSafe AI Data Pipeline
We process 2,000+ raw, unstructured government TDR certificates using **TypeSafe Jev AI**. The AI acts as our Layer 2 pipeline:
- Ingests messy, non-standardized address strings.
- Deterministically classifies submarkets using semantic confidence scoring.
- Automatically generates organic geographic scatter offsets (Fermat's Spiral) to accurately map supply density across the IT corridor.

### 📐 True Financial Underwriting
Instead of illustrative/synthetic math, SECOND LAND runs a genuine Python-backed financial model. It calculates:
- **True BUA** (Base FSI + TDR Multipliers)
- **Granular CapEx** (Submarket-specific TDR pricing + Construction Costs)
- **Discounted Cash Flow (DCF)** solving for exact IRR across 60 discrete property scenarios.

### 🧊 The 3D Feasibility Cube
A custom-built, isometric 3D rendering engine built purely with SVG math to visualize the 'stack'. It allows stakeholders to instantly comprehend the physical relationship between the base allowable build and the vertical extension unlocked by TDR capital.
